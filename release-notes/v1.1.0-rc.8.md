## Gateway API without a crash-looping Traefik CRD install

`v1.1.0-rc.8` builds on `v1.1.0-rc.7`.

- On RKE2 v1.36.x, disabling `rke2-traefik` still installs the
  `rke2-traefik-crd` chart, which bundles its own Gateway API CRDs. With
  Gateway API enabled, those CRDs cannot be imported over the pinned v1.6.1
  CRDs, so the `helm-install-rke2-traefik-crd` job crash-looped in
  `kube-system` (seen live in the `v1.1.0-rc.7` E2E).
- `spec.network.gatewayAPI.enabled` now also requires `rke2-traefik-crd` in
  `spec.rke2.disable`, in both the Go validation and the CRD. The deploy
  template adds it when `gateway_api_enabled` is true, and the E2E cluster
  disables it. Clusters without Gateway API are unchanged.

## Upgrade notes

Apply the CRD chart from this candidate before creating a Gateway API cluster.
