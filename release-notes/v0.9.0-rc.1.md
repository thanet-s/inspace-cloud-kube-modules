## RKE2 Kubernetes 1.36 and Karpenter 1.14.1

`v0.9.0-rc.1` upgrades the supported RKE2 release to
`v1.36.4+rke2r1` (Kubernetes 1.36.4), aligns the Go Kubernetes libraries to
`v0.36.4`, and upgrades the InSpace Karpenter provider to Karpenter `v1.14.1`.
The bootstrap cache inventory is regenerated from the signed RKE2 amd64 image
manifests for this release.

RKE2 v1.36 defaults new clusters to Traefik after ingress-nginx retirement.
The deployment and E2E templates disable both `rke2-traefik` and
`rke2-ingress-nginx`, leaving ingress installation to the cluster operator.
The cache omits the disabled add-on images while retaining them in the audited
inventory for explicit opt-in configurations.

## Upgrade notes

This release candidate changes the immutable control-plane RKE2 and image
inventory pins. Existing clusters are not rewritten by the reconciler; use the
normal guarded destroy/recreate lifecycle when moving an existing cluster to
the new bootstrap release. Existing Karpenter NodePools and NodeClasses remain
API-compatible with the provider upgrade; apply the CRD and workload charts
from this candidate before upgrading the controller image.
