## Dependency and security refresh

v0.8.1 consolidates the outstanding dependency updates for the cloud
controller, CSI driver, Karpenter provider, and release workflows. It upgrades
the Kubernetes libraries to v0.35.7, CEL to v0.29.0, the CSI specification to
v1.13.0, and gRPC to v1.82.1.

The Go modules now use `golang.org/x/text` v0.39.0, resolving GO-2026-5970.
The cloud provider's gRPC update also resolves GO-2026-6061. Pinned GitHub
Actions were refreshed to the versions represented by the superseded
Dependabot pull requests.

## Upgrade notes

This patch release does not change cluster topology, immutable bootstrap
configuration, or ownership schemas. Existing v0.8.0 clusters can upgrade the
released CRD and workload charts in place by setting `modules_version: 0.8.1`
and running `deploy/run.sh update`.
