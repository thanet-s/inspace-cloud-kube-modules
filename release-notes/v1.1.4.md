## v1.1.4

### Storage

- The InSpace CSI node plugin now implements `NodeGetVolumeStats` and
  advertises the `GET_VOLUME_STATS` capability, so kubelet reports volume usage
  (`kubelet_volume_stats_*`) for InSpace volumes. Before, kubelet exported none
  of these metrics, so Grafana volume panels were empty and the
  `KubePersistentVolumeFillingUp` alerts of kube-prometheus-stack could never
  fire. The driver reports bytes (total, used, available) and inodes (total,
  used, available) from `statfs` on the published path. A path that does not
  exist, or that is not a mount point, returns `NotFound`, so kubelet exports no
  number instead of the node's own disk usage. No chart change is needed. After
  the CSI node DaemonSet runs the new image, the metrics appear for volumes that
  are already mounted.
