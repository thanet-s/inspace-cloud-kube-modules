## v1.1.2

### Deploy

- `deploy/run.sh update` and `destroy` now end the deployment journal
  (`state.json`) with a real newline. Before, the file ended with the two
  characters backslash and `n` after the closing `}`, and the next `update`
  failed while loading it with `from_json failed: Extra data`. If you have
  an affected journal, open `state.json` and replace those last two
  characters with a newline, then run `update` again.
