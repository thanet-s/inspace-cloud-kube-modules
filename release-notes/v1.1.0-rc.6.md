## Cilium drift check fix

`v1.1.0-rc.6` builds on `v1.1.0-rc.5`.

- The Cilium configuration drift check no longer rejects healthy agents.
  Cilium 1.20 omits a zero `value` from `cilium-dbg metrics list -o json`, so
  an in-sync `cilium_drift_checker_config_delta` has no value field. A listed
  metric without a value now counts as zero; a missing metric still fails.
  The `v1.1.0-rc.5` E2E failed at this check.
